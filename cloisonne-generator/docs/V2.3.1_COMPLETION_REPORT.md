## 二、平台限制与决策（与规格书差异，需 ChatGPT 知悉）

1. **RestartOnFailure 间隔 5 秒 → 改为 1 分钟**
   Windows Task Scheduler 的 RestartOnFailure `Interval` **最小支持 1 分钟**（PT1M），
   `PT5S` 会报 `HRESULT 0x80041318 (SCHED_E_INVALIDVALUE)` / `Interval:PT5S`。
   已按 **1 分钟 × 5 次** 实现，其余（登录自启、失败重启）完全按规格书。
2. **依赖版本修正（scipy/scikit-learn/shapely）**
   requirements.txt 原锁定 `scipy==1.11.0 / scikit-learn==1.3.0 / shapely==2.0.0`（V2.3 早期版本），
   在 Python 3.12 无对应 wheel，pip 尝试源码编译失败（`cython cannot transpile`）。
   已更新为**系统实测可运行版本**：scipy==1.18.1 / scikit-learn==1.9.0 / shapely==2.1.2。
   系统环境（Python 3.12）与 .venv 均以这些版本实测通过全管线。
3. **start.bat 服务以独立窗口运行**（`start "Cloisonne2Creo Server" /min cmd /k`）
   因为前台运行 `main.py` 会阻塞 start.bat 主流程，无法同时做健康轮询+开浏览器。
   当前实现：服务跑在最小化窗口（关闭该窗口即停止服务），主窗口负责检查→轮询→开浏览器后退出。
4. **.bat 文件必须 CRLF 行尾**
   Write 工具默认 LF，cmd.exe 解析 LF-only .bat 会逐词拆分报错（如 `'+' is not recognized`）。
   已全部归一化为 CRLF；BAT 内日志输出改为 ASCII-only，避免 GBK 乱码（中文路径由 main.py 的 UTF-8 startup.log 记录，记事本/VS Code 打开正常）。
