## 一、P0 后端改造（已完成）

### 1.1 Skan Graph Engine 替换自研 graph

**新增文件**: `backend/lineart/graph_skan.py` — `SkanSkeletonGraph`

- 基于 `skan 0.13.1` 的 Skeleton + csr 图构建
- 统一接口: `extract(self, skeleton, spacing_mm_per_px)`
- Skan 物理尺度: `spacing=[scale, scale]`，branch-distance 直接为 mm 长度
- 输出与 Legacy 兼容格式: nodes + edges (points/length_px/closed)
- 统计: skeleton_pixel_count/junction_count/endpoint_count/branch_count/cycle_count

**旧文件**: `backend/lineart/graph.py` — 标记 Legacy
- 文件头注释说明 V2.2 默认用 Skan
- 末尾增加 `LegacySkeletonGraph = SkeletonGraph` 别名
- 保留为 fallback（Skan 失败时自动回退）

### 1.2 线稿验证语义重构

**新增文件**: `backend/lineart/validator.py` — `LineArtValidator`

**新验证语义**（规格书核心要求）:
- `hard_collision`: 曲线**中间部分**距离 < wire_diameter(0.6mm) → **error**
  - 端点/junction 处的曲线连接**不判定**为碰撞（最近点在两端 0.25mm 内跳过）
- `dense_spacing_warning`: wire_diameter ≤ distance < recommended_spacing(0.8mm) → **warning**（不是 error）
- `self_intersection`: Shapely `is_simple` 检测
- `small_radius`: 曲率半径 < min_radius(1.0mm)

**状态判定**:
- hard_collision > 0 → error
- hard == 0 && dense > 0 → warning
- 都为 0 → ok

### 1.3 Stroke/Branch/Centerline 命名重构

**修改**: `backend/lineart/pipeline.py`

- result 输出新增: `strokes`/`branches`/`centerlines`/`junctions`/`endpoints`
- 兼容旧字段: `boundaries`/`curves` 保留
- `lineart_stats` 新增: skeleton_pixel_count/junction_count/endpoint_count/branch_count/cycle_count/raw_branch_count/final_curve_count/merged_curve_count
- graph_engine 配置默认 `"skan"`，失败自动 fallback legacy
- 用 `LineArtValidator` 替换旧 `CurveValidator`

## 三、Skan vs Legacy A/B 对比

**测试图**: 用户线稿（黑白卡通线稿，1107×1107，输出100mm）

| 指标 | Skan (默认) | Legacy | 说明 |
|------|------------|--------|------|
| Branch数 | **200** | 578 | -65.4% |
| Node数 | 177 | 401 | -55.9% |
| Junction数 | 146 | 341 | Skan 合并碎边 |
| Endpoint数 | 54 | 60 | 接近 |
| Cycle数 | **15** | 11 | Skan 环识别更准(眼睛椭圆等) |
| 平均边长(px) | **104.4** | 36.5 | Skan 碎边合并更好 |
| 实体碰撞 | 1 | 1 | 接近 |
| 过密警告 | 15 | 19 | Skan 略优 |
| 自交 | 0 | 0 | 都为0 |
| 运行时间(s) | 2.287 | 0.06 | Skan 慢但可接受 |

**结论**: Skan 几何正确性更高（碎边合并、环识别），Curve 数量减少 65.4%（远超规格书 20% 目标），选为默认引擎。运行时间 2.3s 在可接受范围（规格书未设性能上限）。

## 五、API 变更

### 5.1 新参数
| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `gen_mode` | str | "auto" | 生成模式（兼容旧 `generate_mode`） |
| `recommended_spacing_mm` | float | 0.8 | 推荐线间距（兼容旧 `min_wire_spacing_mm`） |
| `binary_threshold` | str | "" | 二值阈值，空=Otsu |
| `denoise_ksize` | int | 3 | 去噪核 |
| `min_spur_length_mm` | float | 0.8 | 毛刺阈值 |
| `keep_fine_segments` | bool | False | 保留细小线段 |
| `skeleton_method` | str | "skeletonize" | 中心线算法 |
| `graph_engine` | str | "skan" | Graph引擎: skan/legacy |

### 5.2 线稿模式返回字段
- `mode`: "lineart"
- `engine`: "lineart_skeleton"
- `auto_detection`: 自动检测结果（auto 模式）
- `lineart_stats`: 线稿统计
- `strokes`/`branches`/`centerlines`/`junctions`/`endpoints`
- `validation`: hard_collision_count/dense_spacing_warning_count/self_intersection_count
- `preview_images`: original/binary/skeleton/pruned_skeleton/final_curves

## 七、已知限制

1. **Skan 运行时间**: 2.3s vs Legacy 0.06s，大图可能更慢
2. **hard_collision 判定**: 端点容差 0.25mm，极近的非连接曲线可能被误排除
3. **自动检测**: 灰度图/低饱和彩色图可能误判为线稿
4. **medial_axis**: 代码保留但 UI 隐藏（规格书 P2）
