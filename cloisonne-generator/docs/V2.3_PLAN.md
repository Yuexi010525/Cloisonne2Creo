## 最终验收标准
- LineArt: 粗线→单中心线 + self_intersection ≈ 0
- Color: Shared Boundary 保持原有逻辑
- Frontend: LineArt→Color / Color→LineArt / SVG→SVG / A→B 异步均无旧数据残留
- Validation: hard_collision / dense_warning 分开
- 所有测试数据来自真实运行，不造假
